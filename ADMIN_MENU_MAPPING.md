# Pemetaan Menu Admin ke Website Publik

Menu Admin disusun mengikuti urutan navigasi website publik agar editor langsung mengetahui bagian mana yang sedang diubah.

## Menu Website

### Beranda
- Isi Beranda -> `/admin/beranda`
- Hero Banner -> `/admin/hero`
- Pengumuman -> `/admin/pengumuman`
- Agenda -> `/admin/agenda`

### Profil
- Profil Kelurahan -> `/admin/profil`
- Pemerintahan / Aparatur -> `/admin/aparatur`

### Layanan
- Layanan -> `/admin/layanan`

### Berita
- Berita -> `/admin/berita`

### KKN
- Statis dan tidak diedit dari Admin.
- Seluruh konten KKN tetap berasal dari `src/data/kknStatic.ts`.

### Informasi
- Wilayah -> `/admin/wilayah`
- Data RT -> `/admin/rt`
- Galeri -> `/admin/galeri`
- Dokumen -> `/admin/dokumen`
- Kontak & Jam Layanan -> `/admin/kontak`

## Administrasi
- Pesan Masuk -> `/admin/pesan`
- Pengaturan Website -> `/admin/pengaturan`
- Pengguna Admin -> `/admin/pengguna` (Super Admin)

Catatan: grup Administrasi bukan menu publik. Grup ini hanya untuk pengelolaan sistem dan website.
