KKN PREMIUM READY

Cara pakai:
1. Copy folder public/images/kkn ke project kamu.
2. Copy KknPage.tsx ke src/components/public/KknPage.tsx.
3. Copy KknPage.module.css ke src/components/public/KknPage.module.css.
4. Copy page.tsx ke src/app/tim-kkn/page.tsx.
5. Jalankan npm run build.
