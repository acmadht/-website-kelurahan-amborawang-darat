Ini bukan dashboard baru terpisah. Paket dibuat dari src project yang dikirim.

- Admin Tim KKN dihapus total.
- Menu Tim KKN di admin dihapus.
- Halaman publik Tim KKN dibuat static/hard-coded + flip klik.
- HomePage tidak lagi membaca data KKN dari Firestore.
- Admin Beranda ditambah.

- Admin Kontak & Jam Pelayanan ditambah.
- Pemerintahan/Lembaga dilengkapi kategori LPM, TP PKK, Karang Taruna, Adat, Linmas, Bhabinkamtibmas, Babinsa, Staf.

- Dashboard admin dirapikan dan cakupannya diperjelas.
- Pengaturan ditambah favicon.
