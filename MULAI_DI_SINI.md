# Mulai di Sini

Urutan tercepat agar website dapat dipakai:

1. Instal Node.js 20.9 atau lebih baru.
2. Ekstrak ZIP dan buka folder proyek melalui VS Code.
3. Jalankan `npm install`.
4. Salin `.env.example` menjadi `.env.local`.
5. Buat proyek Firebase dan akun Cloudinary.
6. Isi seluruh environment variables.
7. Jalankan `npm run bootstrap-admin`.
8. Jalankan `npm run seed`.
9. Jalankan `npm run dev`.
10. Buka `http://localhost:3000/admin/login`.
11. Ganti semua data contoh melalui dashboard admin.
12. Upload ke GitHub dan deploy ke Vercel.

Baca `README.md` untuk langkah terperinci dan `PANDUAN_REVISI.md` untuk lokasi setiap perubahan.
