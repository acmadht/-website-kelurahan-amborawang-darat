DOKUMEN PUBLIK
==============
Simpan file dokumen pada folder:
public/dokumen/

Nama file yang dipakai contoh:
profil-kelurahan-amborawang-darat.pdf
formulir-pelayanan-administrasi.docx
perda-kukar-nomor-6-tahun-2020.pdf
perbup-kukar-nomor-43-tahun-2019.pdf
rekapitulasi-data-wilayah.pdf
laporan-informasi-publik.pdf

Data dokumen dapat diubah di:
src/components/public/DocumentsPage.tsx

Fitur:
- pencarian dokumen
- filter kategori
- metadata tahun/format/ukuran
- tombol lihat
- tombol unduh
- empty state
- responsive desktop/tablet/HP

PENTING:
Pastikan hanya dokumen yang memang boleh dipublikasikan yang dimasukkan.
