# Placeholder Template Surat Google Docs

Gunakan placeholder berikut di Google Docs resmi kelurahan:

- `{{ID_SURAT}}`
- `{{NOMOR_SURAT}}`
- `{{TANGGAL}}`
- `{{NAMA}}`
- `{{NIK}}`
- `{{RT}}`
- `{{JENIS_SURAT}}`
- `{{KEPERLUAN}}`
- `{{PETUGAS}}`
- `{{URL_VERIFIKASI}}`

QR verifikasi ditambahkan otomatis pada bagian akhir dokumen saat PDF final dibuat.

Jangan memakai template default sebagai surat resmi sebelum kop, redaksi, pejabat penandatangan, klasifikasi surat, dan ketentuan tata naskah telah disesuaikan dengan standar Kelurahan Amborawang Darat.
