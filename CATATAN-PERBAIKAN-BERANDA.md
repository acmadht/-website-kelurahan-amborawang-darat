# Perbaikan Beranda Amborawang Darat

## Cara memasang

1. Salin seluruh folder dalam paket ini ke folder utama proyek.
2. Setujui penggantian file yang memiliki nama sama.
3. Hapus folder `.next` bila ada.
4. Jalankan `npm run dev` kembali.
5. Buka halaman dengan hard refresh menggunakan `Ctrl + F5`.

## Perubahan utama

- Logo memakai file lokal `public/images/logo-amborawang-darat.png` sehingga tidak bergantung pada URL lama di Firebase.
- Ruang transparan berlebih pada logo sudah dipotong. Logo tampil lebih besar, solid, proporsional, dan tidak terpotong.
- Foto kantor resmi dipasang pada hero beranda.
- Alamat, nomor kontak, jam pelayanan, dan peta disesuaikan dengan data listing Google Maps yang ditemukan.
- Sambutan lurah diperbaiki.
- Data beranda diubah menjadi 2.921 penduduk, 633 kepala keluarga, dan 13 RT. Statistik RW dihapus dari beranda.
- Data aparatur diperbarui berdasarkan daftar ASN Kecamatan Samboja Barat tahun 2026.
- Nama lurah: A. Achmad Dendi, S.Sos.
- Foto resmi aparatur belum ditemukan dalam sumber publik yang dapat diverifikasi untuk digunakan ulang. Paket memakai placeholder profesional. Foto dapat diganti dari dashboard admin tanpa mengubah kode.

## Catatan verifikasi sebelum publikasi

Nomor telepon dan jam pelayanan berasal dari listing Google Maps pihak ketiga yang menandainya sebagai data historis. Konfirmasikan kembali kepada Kantor Kelurahan Amborawang Darat sebelum website dipublikasikan secara resmi.

Data kepala keluarga yang tersedia berasal dari LKjIP Kecamatan Samboja tahun 2022. Data penduduk berasal dari BPS tahun 2023. Perbarui melalui dashboard apabila kelurahan memiliki data administrasi penduduk yang lebih baru.
