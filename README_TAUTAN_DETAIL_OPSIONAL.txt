TAUTAN DETAIL PROGRAM KKN - OPSIONAL

Perubahan:
- Tautan Detail tidak wajib diisi.
- Jika Tautan Detail kosong, tombol detail tidak ditampilkan di halaman publik.
- Jika Tautan Detail diisi, tombol detail tampil otomatis.
- Teks Tombol juga opsional.
- Jika URL diisi tetapi Teks Tombol kosong, publik memakai teks default "Lihat Detail".

Contoh tanpa detail:
Tautan Detail: [kosong]
Teks Tombol: [kosong]
=> Tidak ada tombol pada kartu program.

Contoh dengan detail:
Tautan Detail: /berita/program-literasi-digital
Teks Tombol: Baca Selengkapnya
=> Tombol "Baca Selengkapnya" tampil pada kartu program.
